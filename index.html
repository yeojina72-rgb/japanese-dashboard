✏️ 헷갈리는 포인트 4가지 펼치기
とどかなかったから

~라서 = から, ~하면 = たら. 둘을 구분해서 읽어요.
下から手をのばしても とどかなかったから — 손을 뻗어도 닿지 않아서

けが

상처, 부상. 毛(け, 털)가 아니에요.
子ねこが けがをしなくて — 새끼고양이가 다치지 않아서

ないていたんだ

울고 있었어 (나이테 · 이탄다). 鳴く(なく) + ていた + んだ.
ニャーニャー ないていたんだ — 야옹야옹 울고 있었어

～だけだし

~것뿐이고. 가볍게 이유를 댈 때 쓰는 말투예요.
ちょっとかまれただけだし — 조금 물린 것뿐이고

☀️ 11/25 짚고 갈 점 3가지 펼치기
おおあめ

앞의 おお를 길게 — 오오아메. 반대는 小雨(こさめ, 가랑비).
大雨が降る — 폭우가 내리다

～やすくなっています

순서가 중요해요: 降りやすい → 降りやすくなる → 降りやすくなっています.
あめがふりやすくなっています / 雨が降りやすくなっています — 비가 내리기 쉬워졌어요

～ため

회화의 から 대신, 뉴스·예보·안내문에서는 ため. 원인을 차분하게 전하는 말투예요.
大雨や雷があるかもしれないため、ご注意ください — 폭우나 천둥이 있을 수 있으므로 주의해 주세요

💡 11/26 짚고 갈 점 3가지 펼치기
いつ・どこ + ても

いつ·どこ 뒤에는 を를 붙이지 않아요. 何를 쓸 때만 を가 붙어요.
いつ行っても(언제 가도) · どこで食べても(어디서 먹어도) · 何を探しても(뭘 찾아도)

空いている

같은 한자, 두 가지 뜻 — お腹が空いている 배가 고프다 / 店・道がすいている 한산하다. 안 고플 때는 空いていない.
お腹が空いていない時は — 배가 고프지 않을 때는

おちそう / ごちそう

落ちそうです는 '떨어질 것 같아요', 倒れそうです는 '쓰러질 것 같아요'. ごちそう(대접)와 발음이 헷갈리지 않게요.
おちそうだったんだけど — 떨어질 것 같았는데 · 破れそうです — 찢어질 것 같아요

💡 11/27 짚고 갈 점 4가지 펼치기
금지형 42문제 규칙

동사 기본형 + な 하나로 끝나요. Ⅰ그룹 書(か)く→書くな, Ⅱ그룹 食(た)べる→食べるな, Ⅲ그룹 する→するな·来(く)る→くるな.
借(か)ります → かりるな (かえるな 아님!) · 帰(かえ)ります → かえるな

함정 조사 に · を

탈 때는 に, 내릴 때는 を, 사는 곳은 に. 한국어와 반대라 제일 헷갈려요.
バスに 乗(の)ります · 電車(でんしゃ)を 降(お)ります · 東京(とうきょう)に 住(す)んでいます

の · へ · が

명사+명사 사이엔 の, 이동 방향은 へ(읽을 땐 え), 좋아하다·잘하다·할 수 있다 앞은 が.
駅(えき)の 近(ちか)く · 日本(にほん)へ 行(い)きます · ピアノが 好(す)きです · 英語(えいご)が できます

명령형 ↔ 금지형

같은 동사라도 止(と)まれ는 '멈춰라'(명령), 止(と)めるな는 '세우지 마'(금지).
急(いそ)げ · 走(はし)れ · 寝(ね)ろ · 来(こ)い / 混(ま)ぜるな 危険(きけん)
